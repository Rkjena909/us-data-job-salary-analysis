# Dataset

Source: [Jobs and Salaries in Data Science](https://www.kaggle.com/datasets/hummaamqaasim/jobs-in-data), Hummaam Qaasim, Kaggle.

The supplied historical CSV contains 9,355 records and 12 columns, covering 2020–2023. It is copied unchanged. The current Kaggle version may differ.

Kaggle's dataset metadata lists **Database: Open Database, Contents: Database Contents**. Database rights are governed by [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/); individual contents by [DbCL 1.0](https://opendatacommons.org/licenses/dbcl/1-0/). These dataset terms are separate from the analysis code. Retain this attribution when redistributing the data or a derived database.

Fields: work_year, job_title, job_category, salary_currency, salary, salary_in_usd, employee_residence, experience_level, employment_type, work_setting, company_location, company_size.

Salaries are nominal annual amounts. No inflation adjustment or spelling correction is performed. Identical rows are retained in the main analysis; a separate sensitivity analysis removes exact repeats across all original columns. No individual record identifier is supplied.
